Phase 2 · Free · 10 Minutes
Create a GitHub Account
GitHub hosts your website for free forever
▼
💡
What is GitHub? It's like Google Drive for code. You upload your HTML file there and GitHub makes it a live website — completely free, no credit card needed.
1 Open Chrome on your S22 Ultra

Go to:

https://github.com

Tap "Sign up" (top right)

2 Fill in the signup form
  • Enter your email address
  • Create a password (write it down!)
  • Choose a username — use something like rexcomicsverse or your name
  • Complete the puzzle verification
  • Tap "Create account"
⚠️
Your username will be part of your website URL. For example if you choose rexcomics, your site will be at rexcomics.github.io
3 Verify your email

GitHub sends a code to your email. Open your email app, copy the 6-digit code, paste it in GitHub. You're in!

4 Create a new Repository

A repository is like a folder that holds your website files. Once logged in:

  • Tap the green "New" button or the + icon at the top right
  • Repository name: type exactly rexcomicsverse.github.io
  • Make sure it says Public (not Private)
  • Tick the box that says "Add a README file"
  • Scroll down → tap "Create repository"
✅
Important: The repository name MUST exactly match your username + .github.io — for example if your username is rexcomics, the name must be rexcomics.github.io
5 Upload your HTML file

You're now inside your repository. Follow these taps:

  • Tap "Add file" button
  • Tap "Upload files"
  • Tap "choose your files"
  • Navigate to Downloads folder → select rexcomicsverse.html
  • Wait for upload to complete (you'll see the filename appear)
  • ⚠️ IMPORTANT: Rename it — in the filename box, change it to index.html
  • Scroll down → tap "Commit changes" (green button)
⚠️
The file MUST be named index.html — not rexcomicsverse.html. This tells GitHub "this is my homepage".
🌍
Phase 3 · Free · 5 Minutes
Make It Live on the Internet
Enable GitHub Pages — your free hosting
▼
1 Go to your repository Settings

Inside your repository page (github.com/yourusername/yourusername.github.io):

  • Tap the ⚙️ Settings tab (you may need to scroll the tab bar)
  • Scroll down the settings page until you see "Pages" in the left menu
  • Tap "Pages"
2 Enable GitHub Pages
  • Under "Source", tap the dropdown that says "None"
  • Select "main" (or "master")
  • Leave folder as "/ (root)"
  • Tap "Save"
3 Wait 2 minutes then visit your site

GitHub takes about 1–2 minutes to build your site. Then open a new tab and go to:

https://YOURUSERNAME.github.io

Replace YOURUSERNAME with your actual GitHub username.

🎉
Your website is now LIVE on the internet! Anyone in the world can visit it. Share the link with friends to test it.
4 How to update your site in future

Whenever you want to change something:

  • Go to github.com → your repository
  • Tap index.html → tap the ✏️ pencil edit icon
  • Make changes → scroll down → tap "Commit changes"
  • Wait 2 minutes → your live site is updated automatically
💡
For bigger edits, download the file → edit it on your phone using a code editor app like Acode (free on Play Store) → re-upload to GitHub

Phase 4 · Free · 20 Minutes
Set Up Firebase
Real login system + database for readers
▼
💡
What is Firebase? It's Google's free backend. It handles: user accounts (sign in / sign up), storing comments, saving reader preferences, and file storage for your comic images. Free up to 50,000 users/month.
1 Create a Firebase project

Open Chrome → go to:

https://console.firebase.google.com

Sign in with your Google account → tap "Create a project"

  • Project name: rex-comicsverse
  • Tap Continue → disable Google Analytics (not needed) → tap "Create project"
  • Wait 30 seconds → tap "Continue"
2 Enable Authentication (Login system)
  • In your project dashboard, tap the 🔨 Build menu on the left
  • Tap "Authentication"
  • Tap "Get started"
  • Under "Sign-in method", tap "Email/Password"
  • Toggle the first switch to Enable
  • Tap "Save"
💡
To also enable Google Sign-In: go back to Sign-in methods → tap "Google" → enable it → add your support email → Save.
3 Enable Firestore (Database)
  • Tap Build → Firestore Database
  • Tap "Create database"
  • Choose "Start in test mode" (you can secure it later)
  • Select a location close to India: choose asia-south1 (Mumbai)
  • Tap "Enable"
4 Enable Storage (for comic images)
  • Tap Build → Storage
  • Tap "Get started"
  • Choose "Start in test mode"
  • Select asia-south1 (Mumbai) → tap Done
5 Get your Firebase config keys

This is the important step — you need to copy these keys into your HTML file.

  • Tap the ⚙️ gear icon → "Project settings"
  • Scroll down to "Your apps" section
  • Tap the </> (Web) icon
  • App nickname: Rex Comicsverse Web
  • Tap "Register app"
  • You'll see a block of code like this:
const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "rex-comicsverse.firebaseapp.com", projectId: "rex-comicsverse", storageBucket: "rex-comicsverse.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc123" };

Screenshot this entire block — you'll need it in Phase 4 Step 6.

6 Add Firebase to your HTML file

Now go to GitHub → tap your index.html → tap the ✏️ pencil icon to edit it.

Press Ctrl+F (or use Chrome's find) to search for:

YOUR_FIREBASE_API_KEY

Replace all the placeholder values with the real values from your Firebase config. There are 6 values to replace:

Find thisReplace with
YOUR_FIREBASE_API_KEYYour actual apiKey value
YOUR_PROJECT.firebaseapp.comYour authDomain
YOUR_PROJECT_IDYour projectId
YOUR_PROJECT.appspot.comYour storageBucket
YOUR_SENDER_IDYour messagingSenderId
YOUR_APP_IDYour appId

After replacing all 6, scroll down and tap "Commit changes". Firebase is now connected!

Phase 5 · 30 Minutes
Set Up Payments
Razorpay for India + Stripe for international
▼
⚠️
You need to be 18+ years old and have a bank account to receive payments. Both Razorpay and Stripe require identity verification (Aadhaar/PAN for Razorpay).

🇮🇳 RAZORPAY — For Indian Readers (UPI, Cards, Net Banking)

1 Create Razorpay account

Open Chrome → go to razorpay.com → tap "Sign up"

  • Fill in your name, email, phone number, business name
  • For "Business Type" select "Individual" or "Proprietorship"
  • Verify your phone with OTP
  • Verify your email
2 Complete KYC (identity verification)

Razorpay needs to verify you before you can receive money:

  • Go to Dashboard → Account & Settings → KYC
  • Upload your PAN card photo
  • Upload your Aadhaar card (front + back)
  • Add your bank account details (account number + IFSC)
  • Approval takes 1–3 business days
✅
Once approved, money from Indian readers goes directly to your bank account every 2 days!
3 Get your Razorpay Key ID
  • In Razorpay Dashboard → tap Settings → API Keys
  • Tap "Generate Test Key" first (for testing)
  • Copy the Key ID — it starts with rzp_test_
  • Go to your Rex Comicsverse site → tap Creator Dashboard
  • Go to Payment Integrations → paste the key → tap Save
💡
Use rzp_test_ key while testing. Once KYC is approved, generate a rzp_live_ key for real payments.

🌍 STRIPE — For International Readers (USD, EUR, GBP)

1 Create Stripe account

Go to stripe.com → tap "Start now"

  • Enter email and password
  • Verify your email
  • Fill in your personal details and business info
  • Add your bank account for payouts
⚠️
Stripe India requires a registered business (GST number or at minimum PAN). If you're an individual, use Stripe Atlas or set up a simple proprietorship.
2 Alternative: Use Gumroad instead

If Stripe India is complex for now, Gumroad is much simpler for international payments:

  • Go to gumroad.com → Sign up free
  • Create a product: "The Indian — Premium Membership" → set price $4.99/month
  • Get your product link
  • In your Dashboard → Payment Integrations → paste your Gumroad URL
  • Gumroad deposits to PayPal or bank every Friday
✅
Gumroad takes only 10% commission and works immediately — no business registration needed. Best option to start fast.

❤️ PATREON — Monthly Memberships

1 Set up Patreon

Go to patreon.com → tap "Create on Patreon"

  • Sign up → choose "Comics" as category
  • Create 3 tiers matching your site: Free (₹0), Dharma Fan ($4.99), Patriot Hero ($9.99)
  • Add descriptions and perks to each tier
  • Connect your bank for payouts (Patreon pays monthly)
  • Copy your Patreon page URL
  • Go to your Rex Comicsverse Dashboard → Payment Integrations → paste URL → Save

Phase 6 · ~₹800/year
Get a Custom Domain Name
rexcomicsverse.com instead of github.io
▼
💡
Optional but highly recommended. rexcomicsverse.com looks far more professional than yourusername.github.io. Costs about ₹800–1000/year (~$10).
1 Buy a domain from Hostinger (easiest for India)

Go to hostinger.in (or namecheap.com for cheaper international prices)

  • Search for rexcomicsverse.com
  • If taken, try rexcomics.in or theindiancomic.com
  • Add to cart → pay (UPI/cards accepted)
  • .in domains are cheap (~₹500/year) and great for Indian platforms
2 Connect domain to GitHub Pages
  • In your domain provider dashboard, find DNS Settings
  • Add 4 new A records pointing to GitHub's IPs:
185.199.108.153 185.199.109.153 185.199.110.153 185.199.111.153

Also add a CNAME record:

Name: www Value: YOURUSERNAME.github.io
3 Tell GitHub your domain
  • GitHub → your repository → ⚙️ Settings → Pages
  • Under "Custom domain" type your domain: rexcomicsverse.com
  • Tap Save → wait 10–30 minutes
  • Tick "Enforce HTTPS" (makes it secure)
🎉
After DNS propagates (up to 24 hours), your site is live at rexcomicsverse.com!

Phase 7 · Free → Then ₹2,000/year
Create Your Android App
Two methods — Easy way and Full way
▼
💡
You have two options. Start with Option A (10 minutes, free) to get an app working immediately. Option B is the full native app (weeks, but better experience).

✅ OPTION A — Convert Website to App (10 Minutes, Free)

1 Use PWABuilder — make your website an app

Go to:

https://www.pwabuilder.com
  • Enter your website URL: https://yourusername.github.io
  • Tap "Start"
  • It will analyze your site (takes 30 seconds)
  • Tap "Package for stores"
  • Choose Android
  • Tap "Generate"
  • Download the .apk file
✅
You now have an .apk file that anyone can install on their Android phone! Share it via WhatsApp, Telegram, or your website's download button.
2 Add a manifest file to your website first

Before PWABuilder, add this to your index.html inside the <head> tag. Edit your file on GitHub and add:

<link rel="manifest" href="manifest.json"> <meta name="mobile-web-app-capable" content="yes"> <meta name="apple-mobile-web-app-capable" content="yes">

Then create a new file in GitHub called manifest.json with this content:

{ "name": "Rex Comicsverse", "short_name": "RexComics", "description": "The Indian — India's greatest superhero comic", "start_url": "/", "display": "standalone", "background_color": "#0B0C10", "theme_color": "#FF6F00", "orientation": "portrait", "icons": [ { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" }, { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" } ] }

Phase 8 · $25 One-Time Fee
Publish to Google Play Store
Make your app available for all Android users
▼
1 Create Play Console account

Open Chrome → go to:

https://play.google.com/console
  • Sign in with Google account
  • Pay the one-time $25 registration fee (~₹2,100)
  • Fill in developer profile (name, email, phone, address)
  • This is a one-time fee — you can publish unlimited apps forever
2 Create your app listing
  • Tap "Create app"
  • App name: Rex Comicsverse
  • Default language: English (India)
  • App type: App
  • Category: Comics
  • Free or paid: Free (recommended to start)
  • Tap "Create app"
3 Fill in Store Listing
  • Short description (80 chars): "The Indian — India's greatest patriot superhero comic. Free to read!"
  • Full description: Describe your comic, characters, what makes it special
  • App icon: 512×512px PNG — your RC logo or The Indian character art
  • Feature graphic: 1024×500px banner image
  • Screenshots: Take 2–8 screenshots of your website on your S22 Ultra
💡
Take screenshots directly on your S22 Ultra by pressing Volume Down + Power button. Screenshot your website pages in Chrome and upload them as app screenshots.
4 Upload your APK / AAB file
  • Go to Release → Production
  • Tap "Create new release"
  • Upload your .aab or .apk file (from PWABuilder or Android Studio)
  • Add release notes: "First release of Rex Comicsverse — The Indian superhero comic platform"
  • Tap "Review release"
5 Submit for review
  • Complete the content rating questionnaire (takes 5 minutes)
  • Set target audience: 13+ or Everyone
  • Fill in privacy policy URL (create a simple one at privacypolicygenerator.info)
  • Tap "Submit for review"
  • Google reviews take 3–7 days for first submission
🎉
Once approved, your app is live on the Play Store! Search "Rex Comicsverse" on Play Store and there it is.
