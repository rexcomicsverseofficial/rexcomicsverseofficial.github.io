## 🚀 Quick Start

### Option 1 — Using Claude Code (Recommended)
```bash
# Install Claude Code first (on PC/Mac/Termux)
npm install -g @anthropic-ai/claude-code

# Then run it in this folder
cd rex-comicsverse
claude
```
Then just type: **"Deploy my website to GitHub Pages"** — Claude Code does everything.

### Option 2 — Manual (1 minute)
```bash
bash setup.sh
```

### Option 3 — Web Only (No terminal needed)
1. Go to github.com → Create repo named `yourusername.github.io`
2. Upload `index.html`, `manifest.json`, `sw.js`
3. Settings → Pages → Enable → Done!
